# Сайт студии «MALAMUT»: как всё устроено

## Что где лежит

- `index.html`, `style.css`, `app.js` — сам сайт.
- `works.json` — список работ: названия, файлы, обложки, слова для караоке.
- `media/` — видео, музыка, фото и обложки.
- `assets/` — заставка студии.
- `config.js` — настройки: хранилище на GitHub и ключи Firebase для реакций.
- `firestore.rules` — правила для реакций, их нужно вставить в Firebase (шаг 3).

## Шаг 1. Включить сайт (GitHub Pages)

1. Откройте https://github.com/malamut2022/malamut-studio/settings/pages
2. В разделе **Build and deployment** выберите **Source: Deploy from a branch**.
3. В **Branch** выберите `main`, папку `/ (root)` и нажмите **Save**.
4. Через 1–2 минуты сайт откроется по адресу https://malamut2022.github.io/malamut-studio/

## Шаг 2. Ключ автора, чтобы добавлять работы с сайта

1. Откройте https://github.com/settings/personal-access-tokens/new
2. **Token name:** `malamut-site`.
3. **Expiration:** выберите 1 год (или «No expiration»).
4. **Repository access:** выберите *Only select repositories*, затем `malamut-studio`.
5. **Permissions → Repository permissions → Contents:** выберите *Read and write*.
6. Нажмите **Generate token** и скопируйте ключ (он начинается с `github_pat_`).
7. На сайте внизу нажмите **«Вход для автора»** и вставьте ключ.

Ключ хранится только в вашем браузере. На другом телефоне или компьютере войдите тем же ключом.
Никому его не показывайте: с ним можно менять сайт.

## Шаг 3. Реакции ❤️ 🔥 💩 (Firebase, бесплатно)

1. Откройте https://console.firebase.google.com и нажмите **Создать проект** (Create project).
   Название: `malamut-studio`. Google Analytics можно выключить.
2. Слева выберите **Build → Authentication → Get started**.
   На вкладке **Sign-in method** выберите **Anonymous**, включите и сохраните.
3. Слева выберите **Build → Firestore Database → Create database**.
   Регион: `eur3 (europe-west)`, режим: **production**.
4. На вкладке **Rules** удалите всё и вставьте содержимое файла `firestore.rules`, затем нажмите **Publish**.
5. Нажмите шестерёнку → **Project settings**. Внизу в **Your apps** нажмите значок `</>` (Web).
   Название приложения: `site`. Нажмите **Register app**.
6. Скопируйте блок `firebaseConfig` (apiKey, authDomain, projectId…) и пришлите Claude.
   Эти ключи не секретные: они и так видны в коде любого сайта.
   Claude вставит их в `config.js`, и реакции появятся.
7. В **Authentication → Settings → Authorized domains** добавьте `malamut2022.github.io`
   и, когда появится, ваш домен.

## Шаг 4. Свой адрес (домен)

1. Купите домен, например на https://www.reg.ru (имя .ru стоит около 200–300 ₽ за первый год).
2. В настройках DNS домена добавьте записи:
   - четыре записи **A** для `@`: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`;
   - запись **CNAME** для `www`: `malamut2022.github.io`.
3. Напишите Claude имя домена: он добавит его на сайт.
   После этого в настройках Pages (шаг 1) поставьте галочку **Enforce HTTPS**, когда она станет доступна.

## Как добавлять работы

Войдите как автор, нажмите **«+ Добавить»**, выберите файл, напишите название и нажмите «Опубликовать».
Раздел сайт выбирает сам: видео попадают в «Видео», музыка в «Музыку», фото в «Фото», тексты и PDF в «Проекты».
Гости увидят работу через 1–2 минуты.

- Файл до 95 МБ.
- Видео с iPhone в формате HEVC многие браузеры не показывают. Сайт предупредит об этом.
  Такое видео лучше прислать Claude, а на будущее включить на iPhone:
  Настройки → Камера → Форматы → «Наиболее совместимые».
- Караоке: откройте песню и нажмите «Сделать караоке».
